# GANIT Premium Design System

## Brand Identity
**Name**: GANIT (ગણિત)
**Tagline**: ગણિતને મનોરંજક બનાવો
**Personality**: Calm confidence + playful discovery. Youthful but never childish. Academic excellence meets modern delight.

## Color Palette

### Primary
- **Indigo Deep** `#1E3A5F` — Primary text, headers
- **Indigo** `#3B82F6` — Primary actions, links
- **Indigo Soft** `#60A5FA` — Hover states

### Accent (Energy)
- **Saffron** `#F59E0B` — XP, highlights, CTAs
- **Saffron Soft** `#FBBF24` — Soft glows
- **Emerald** `#10B981` — Success, correct answers
- **Rose** `#F43F5E` — Gentle error (never harsh)

### Neutrals
- **Canvas** `#F8FAFC` — Background
- **Surface** `#FFFFFF` — Cards
- **Muted** `#64748B` — Secondary text
- **Border** `#E2E8F0` — Dividers

### Dark Mode
- **Canvas Dark** `#0F172A`
- **Surface Dark** `#1E293B`
- **Text Dark** `#F1F5F9`

## Typography
- **Gujarati**: `Noto Sans Gujarati` (primary), fallback `Nirmala UI`
- **English / Numbers**: `Inter` / `SF Pro`
- **Math**: `KaTeX` or `MathJax` with clean rendering

### Scale
- Display: 32–40px bold
- Title: 24px semibold
- Body: 16px regular
- Caption: 13px medium
- Micro: 11px

## Spacing (4px base)
4, 8, 12, 16, 20, 24, 32, 40, 48, 64

## Radius
- sm: 8px
- md: 12px
- lg: 16px
- xl: 24px
- full: 9999px

## Motion
- Duration: 200ms (micro), 300ms (ui), 500ms (page)
- Easing: `cubic-bezier(0.22, 1, 0.36, 1)`
- Respect `prefers-reduced-motion`

## Components
- Cards: soft shadow + subtle border
- Buttons: solid primary, soft secondary, ghost tertiary
- Progress: animated rings + bars
- Bottom nav: 5 items max, large touch targets (≥44px)

## Chapter Worlds (Visual Motifs)
1. Relations & Functions → **Connections** (nodes & lines)
2. Inverse Trigonometry → **Angles** (arcs & rays)
3. Matrices → **Matrix Lab** (grid cells)
4. Determinants → **Logic Grid**
5. Continuity & Differentiability → **Calculus Flow**
6. Applications of Derivatives → **Motion Curves**
